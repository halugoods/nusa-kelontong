# NUSA Kelontong — Aplikasi Kasir

![NUSA](https://img.shields.io/badge/version-1.0.0-blue)

Aplikasi Kasir POS untuk untuk Kelontong.

## ✨ Fitur Unggulan
- 🔐 Google Sign-In
- 📦 Manajemen Produk & Stok
- 💰 Transaksi POS / Kasir
- 📊 Laporan Penjualan Harian/Bulanan
- 👥 Manajemen Karyawan (Owner/Manager/Kasir/Gudang/Finance)
- 📱 QRIS Payment
- 🖨️ Thermal Printer via Bluetooth
- ☁️ Backup & Restore ke Cloud (Supabase)
- 🌙 Dark Mode
- 📊 Grafik & Chart Penjualan
- 🔢 Barcode Scanner
